# protocol

Wire format shared by every sender and receiver.

- `SPEC.md` — protocol spec: v2 (today's `Q2H`/`Q2D` text frames, PLAN P0.4) and v3 (binary frames, PLAN P0.5).
- `test-vectors/` — inputs, parameters and expected frames. Every codec (Python, JS, Kotlin, Swift, Go) must reproduce them exactly.
