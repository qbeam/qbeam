qbeam

Copy-paste for locked-down machines. Send a file from your terminal to your phone over animated QR codes: no network, no USB, no admin rights.

Open the receiver Source on GitHub

Send

uvx qbeam send app.log

Or pipx install qbeam, npx qbeam send app.log, or the single file qbeam.pyz from the latest release (python3 qbeam.pyz send app.log). Every option installs without admin rights.

Receive

  1. On your phone, open qbeam.dev/r in Chrome or Safari and add it to your home screen. It keeps working offline. On Android, the app is faster.
  2. Point the camera at the codes on the sending screen.
  3. The file saves once it's complete and its SHA-256 checks out.

Android app

Native decoding at about 280 KB/s, saves to Downloads/qbeam, and no internet permission. Android 10 or later.

Download the APK Open qbeam-<version>.apk on the phone and allow installs from your browser.

Check it against the .sha256 file beside it. Signing certificate (SHA-256):

What you get

FastHundreds of KB/s in a browser, using grids of QR codes and a fountain code, so missed frames never mean waiting for a loop.
Terminal modeOver SSH or without a browser, --tty draws the codes right in the terminal.
Folders & stdinqbeam send ./project sends one archive and respects .gitignore; cat log | qbeam send - works too.
Optional encryption--encrypt uses AES-256-GCM with a passphrase you type on the phone.
Open source (Apache-2.0). qbeam makes no network connections and collects no data. Use it only to move data you're authorised to move: anyone who can see the sending screen can read an unencrypted transfer. Privacy
